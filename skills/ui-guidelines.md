# Guía de interfaz

Tipografía serif para títulos y sans-serif legible para acciones. Colores base: verde `#0f766e`, tinta `#15312d`, arena `#f5f1e8` y acento `#d79537`. Usar escala de espacios de 4/8 px, tarjetas con borde suave, botones primarios visibles y modales con foco contenido.

Cada campo tiene etiqueta persistente, error accionable y estados de carga/éxito. Confirmar eliminaciones, ofrecer estados vacíos con siguiente acción y skeletons en listados. Mantener contraste AA, foco visible, teclado, texto alternativo y objetivos táctiles de 44 px. En móvil, filtros se presentan superpuestos y tablas permiten desplazamiento.
