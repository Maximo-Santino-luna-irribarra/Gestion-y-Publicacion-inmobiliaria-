# Visión general

Horizonte Propiedades es una plataforma ficticia para publicar inmuebles de Lanús, Avellaneda y alrededores. El público explora, filtra, guarda favoritos y consulta. El equipo autorizado administra publicaciones, imágenes, consultas, clientes, visitas y datos institucionales.

El alcance inicial no distingue roles y guarda favoritos en el navegador. Futuras etapas pueden agregar cuentas de visitantes, favoritos sincronizados, permisos, analítica avanzada, firma documental e integraciones de portales. Nunca usar datos personales reales en demos.
