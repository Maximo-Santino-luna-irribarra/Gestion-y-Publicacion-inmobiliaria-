# Pruebas

Backend: unitarias para autenticación, validaciones y servicios; e2e para login, CRUD/filtros/paginación, uploads, consultas, visitas y configuración. Frontend: componentes/formularios y recorridos críticos con API simulada. Los datos siempre son ficticios.

Comandos: `pnpm test`, `pnpm test:e2e`, `pnpm lint` y `pnpm build` dentro de cada proyecto. Para e2e usar una base separada, migrarla/sembrarla y limpiarla al terminar. No apuntar tests a producción.
